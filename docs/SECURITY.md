# 凭据、数据和接口安全设计

## 凭据生命周期

- 平台子 Key 由独立查找标识和至少 256 位随机秘密组成。只存标识、脱敏显示片段和带版本的服务器端 HMAC 摘要，认证时常量时间比较。摘要密钥通过安全存储注入，轮换保留有限期旧版验证或重签发策略。控制面 JWT、子 Key 摘要、LiteLLM 服务 Key、LiteLLM 管理 Key、供应商凭据及回调签名密钥分别管理。
- Key 所有人登录后按待领取记录创建和一次性获取明文。关闭缓存、日志和前端遥测。领取失败需要撤销或重发。暂停、恢复、撤销、轮换和超时均审计。发生泄露先暂停受影响范围，轮换凭据并验证拒绝和恢复。
- 供应商 Key 存在获准的运维密钥系统或受限部署凭据文件，仅 LiteLLM 装载。FastAPI 和界面只处理引用或指纹。通过部署管理轮换和测试，运维操作有身份与审计记录。
- 管理面使用 Argon2id 密码摘要、短期 JWT 及可撤销会话。使用 HttpOnly Cookie 时配合 Secure、SameSite 与写操作 CSRF 校验。上线前检查失效传播、登录限速和安全事件审计。

## 网络与管理接口

| 区域 | 允许连接 |
| --- | --- |
| 企业用户网络 | Nginx TLS 入口；管理 API 与已开放的精确推理路径。 |
| 应用与数据网络 | FastAPI、后台任务可访问业务 PostgreSQL。只有授权服务连 Redis。 |
| 代理网络 | FastAPI 推理访问 LiteLLM 推理端。受限运维身份访问 LiteLLM Admin、`/key/*` 和模型管理路由。 |
| 内部回调网段 | 只有代理发送身份访问指定事件接收路径。业务 ingress 不转发该路径。 |
| 供应商出口 | LiteLLM 使用固定允许的主机、DNS、端口及 TLS。普通用户不能自定义上游地址、供应商密钥或转发头。 |

拒绝 Nginx 默认通配代理，避免 UI、调试、Docs/OpenAPI、管理路由和任意透传被公网访问。管理与推理路径各用单独的头白名单。忽略客户端提供的可信代理标识和内部关联头；认证头在进入内部请求前重建。对业务库和代理库分别配置运行账号、迁移账号与最小权限。

## 回调认证与重放防护

1. 内部 TLS，具备运维条件时验证发送方证书。应用层发送 `X-Hook-Key-Id`、`X-Hook-Timestamp` 和 `X-Hook-Signature`。使用 HMAC-SHA-256 签名，签名材料为依次以换行拼接的版本、发送方、签名 Key ID、时间戳、HTTP 方法、事件路径和原始正文的 SHA-256；比较签名采用常量时间。接收时先限制字节数、核验密钥版本与签名，再解析 JSON。
2. 建议允许 5 分钟时钟偏差，部署前验证 NTP 和告警。重试应重新签名，保持同一事件 ID 和正文。持久唯一键记录来源与事件 ID，完全重复可确认，异文冲突审计并人工核对。签名密钥按来源分配、分版本轮换。
3. 回调禁止传原始 Prompt、响应、认证头、堆栈和凭据。只传规范的模型标识、事件类型、关联 ID、有限数值用量和错误分类。接收端以严格 schema 拒绝额外字段，失败日志只包含安全字段。生产回调的签名、重放、重试、入库和断点恢复均需实测。

## 日志、审计与保留

默认关闭请求和响应全文的持久化、调试记录以及未经批准的第三方遥测。逐层核对 Nginx、FastAPI、LiteLLM spend logs、回调、APM 和备份。对脱敏证据实施独立查询权限、静态加密与限期清理；对管理审计保留追加写入及运营访问记录。试点期限及敏感词规则由信息安全和业务负责人确认。

全局熔断、权限配置和凭据轮换记录操作者、目标和结果。上线前使用合成哨兵值验证所有非授权存储、日志和告警均无原文，检查代理直连、管理路径隔离、授权范围和备份恢复。

## 阶段六实现与阶段七边界

当前子 Key 领取只返回一次原文，业务库保存 SHA-256 摘要和展示片段。版本化 HMAC 和独立查找标识是后续安全设计，迁移应覆盖旧 Key 的兼容期或重发。FastAPI 推理入口使用该凭据实施准入。DeepSeek 普通与流式调用已在隔离环境验证，正式服务凭据及生产边界待验收。

阶段七采用独立的 LiteLLM 服务 Virtual Key。客户端 Key 只由 FastAPI 验证，转发时重建鉴权头并使用服务凭据。服务凭据、管理凭据和供应商凭据分别授权和存储。仅内部管理服务可访问 LiteLLM 管理路由。平台从数据库生成归属快照，传向代理的关联元数据采用白名单。身份字段、请求正文及凭据日志在代理链路逐段验证。

回调用专用密钥与时间窗校验，按事件 ID 去重。结算恢复记录仅保留计量所需的用量字段和关联标识。发布报告使用脱敏的关联信息，保留计量结果和验证边界。

## 统计与费用分析

- 统计、分组、分页总数和详情统一在服务端按账本归属限制可见范围。越权详情返回 404，筛选条件只缩小可见范围。
- 统计响应设置为私有且禁止缓存。后续启用应用层缓存时，缓存键需绑定身份、有效授权范围、企业时区和归一化查询条件。
- 明细仅展示账本计量元数据。发布物采用合成样例，避免收录真实请求标识、账户信息、凭据和内部日志。

## 调用审计与风险告警

- 仅信任运维指定的反向代理地址或专用网段。代理应重建转发头，部署验收应验证外部请求无法伪造来源地址。来源 IP 仅向具备相应权限的超级管理员展示。
- 管理审计摘要只记录字段名称和允许的状态值。风险信号用于人工核查。内容全文采集保持禁用，启用前须完成企业政策审批、员工告知及对权限、脱敏和保留期限的评审。
- 公开报告使用合成样例。真实来源地址、凭据、请求标识、人员信息和原始诊断日志留在获准的内部系统。

## 推理边界与供应商出站

- 推理接口接收已支持的文本内容及客户端工具消息，拒绝外部媒体和文件引用。独立的 LiteLLM 出站仅用于供应商通信。生产环境应限制出站目的地，并验收实际网络策略。
- 本机 DeepSeek 验收使用限模型的推理 Virtual Key，已验证该凭据无法访问管理接口。生产凭据隔离、日志脱敏和管理路由拦截应在目标部署重验。
- 发布报告只保留脱敏结果、用量和费用汇总。真实凭据、请求标识、内部地址、账单明细和运行日志需留在获准的内部环境。

## 提交前检查

- 检查暂存区中的源文件、文档和新增文件。环境文件、私人证书、日志、数据库导出与原始诊断产物留在版本库之外。
- 扫描常见访问令牌格式、带凭据的连接地址、疑似固定密钥和个人数据。使用合成样例及通用配置名，避免共享生产细节。发现泄露时先撤销和轮换，再按仓库流程处理历史。
