# 产品功能与交互

P0 为首版上线范围。P1 为 V1.1 试点扩展。P2 为后续规划，依赖产品评审和接入验证。

## 产品功能清单

| 功能 | P0 交付 | 后续 |
| --- | --- | --- |
| 登录认证 | 本地账号、登录、退出、重置密码、停用、登录安全事件 | P1 企业 IdP 评估 |
| 用户管理 | 账号与状态、主部门分配、项目关系 | P1 批量同步 |
| 部门管理 | 部门列表、启停、主管授权、成员视图 | P1 部门层级与独立费用额度 |
| 项目管理 | 项目资料、授权部门、成员增删、归档、统计入口 | P1 批量成员管理 |
| 角色权限管理 | 普通用户、部门主管、超级管理员，范围查询与后台校验 | P2 自定义角色与审批 |
| API Key 管理 | 管理员授权发放、本人一次领取及后续查掩码、轮换、到期、停发、暂停和撤销 | P1 自助申请与审批 |
| 配额管理 | 项目和 Key 月度费用上限，Key RPM 和并发限制 | P1 独立用户及部门额度、更多阈值 |
| 供应商与模型 | OpenAI、DeepSeek、Anthropic，模型启停、别名、凭据引用和价目版本 | P1 Gemini、豆包、Grok 按路由分别上线 |
| AI Gateway | 三条首发路由、流式、基础工具调用、状态与用量采集 | P1 Codex Responses 及更多客户端和路径 |
| Token 消耗趋势 | 今日默认、日期切换、用量来源和待核对计数 | P1 自定义指标 |
| 部门和项目消费对比 | 在权限范围内看合计、排名及下钻，费用分币种 | P1 授权导出 |
| 调用记录 | 筛选、分页、详情、关联请求和账务状态 | P1 对账导出 |
| 审计日志 | 管理操作、登录安全和证据访问；敏感字段裁剪 | P2 审计平台对接 |
| 风险告警 | 站内列表、规则命中、确认、结案、去重和关联调用 | P1 企业通知渠道 |
| 系统设置 | 企业时区、风险与留存策略、网关开关 | P2 多租户和策略审批 |

## 用户角色和权限矩阵

| 资源或动作 | 普通用户 | 部门主管 | 超级管理员 |
| --- | --- | --- | --- |
| 本人用量、费用、调用元数据 | 读本人 | 读本人及授权部门对应记录 | 全公司读 |
| 部门与项目消费对比 | 仅本人可归属项目用量 | 仅授权部门份额，项目跨部门时按归属过滤 | 全公司读 |
| 成员、部门与项目 | 从本人记录和 Key 查看归属标签 | 读授权部门成员和相关项目基础信息 | 管理全部及授权关系 |
| 子 Key 列表与状态 | 读本人掩码、有效期和限额 | 读授权部门下成员 Key 的掩码和状态 | 签发、暂停、恢复、轮换、撤销 |
| 供应商凭据、模型和价目 | 调用记录中读必要标识 | 同左 | 管理配置、连接验证和轮换；已有凭据只显示引用或指纹 |
| 项目和子 Key 配额 | 读本人 Key 可用额度 | 读授权部门 Key 及本部门归属用量；共同项目额度及其余份额受限 | 管理全部 |
| 管理审计日志 | — | — | 全公司读、不可通过业务界面改写 |
| 风险告警及处置 | 在本人调用详情读风险状态 | 读授权部门告警摘要 | 全公司读、确认、结案 |
| 脱敏风险证据 | — | — | 经单独显式授权读取，访问留痕 |
| 系统设置及全局熔断 | — | — | 管理全部 |

部门主管作用域取当前获授权部门集合，成员名册按当前人员关系查询，历史调用按入场部门快照查询。主管失去部门授权后，原部门详情及汇总立即按新授权范围重新求值。普通用户按调用所有者查看本人历史记录。列表、总数、图表、下钻、通过 ID 查详情、自动补全和下载使用一致数据范围，跨范围详情返回 404。超级管理员归属和敏感证据授权写入独立审计，防止权限变更无记录。子 Key 的调用权限由项目成员状态、部门资格、Key 状态与模型名单共同决定。

## 核心业务流程

1. **开户与发放**。管理员建立部门、人员、项目和授权关系。验证项目、部门、成员和模型后建立待领取记录。Key 所有人登录后领取，服务端在领取时生成明文并仅返回一次。用户可从个人页查看归属、状态和协议配置。领取超时或客户端未收到明文时由管理员撤销并重新发放。
2. **调用与结算**。SDK 或客户端请求网关。平台解析 Key、校验授权、施加限流和预算预留，再交给 LiteLLM。平台采集协议用量，按价格快照记账。未知用量保留待核对，授权用户可在调用详情追踪。
3. **统计与审计**。用户查看本人用量，主管按授权部门对比，管理员全公司查询。高风险请求由管理员按请求 ID 关联审计，查看脱敏证据须独立授权，处置结果留痕。
4. **告警与止损**。规则命中成组告警，管理员确认风险、暂停相关 Key、项目或全局网关，并在复核后恢复或撤销和重发。上游凭据泄露时先隔离对应路由，轮换供应商凭据并验证后恢复。
5. **调岗和离职**。人员关系变更时撤销失去有效授权的 Key，并失效相应会话。新的部门和项目关系核验通过后重新签发。历史风险与账务保留原归属。
6. **运营核对**。管理员定位待核对记录，使用上游标识匹配可用证据。必要时补录带理由的调整项，记录审批或复核人并更新相应统计。无法得到可归因证据时保留待核对状态。
