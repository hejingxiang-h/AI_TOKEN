# AI Token Gateway 需求与技术评审

评审稿 v0.1 · 2026-11-27 · 状态为待确认

AI Token Gateway 面向企业内部 PC 浏览器。开发者领取与个人及项目绑定的子 API Key，通过网关访问公司授权的模型。平台以可追溯的用量、成本和风险记录支撑研发、部门管理和审计。

首版拟采用 FastAPI 模块化单体和独立 LiteLLM Proxy，由平台统一处理身份、组织权限、配额和账本。优先接入 OpenAI、DeepSeek 和 Anthropic Claude。接入结论基于官方资料，目标环境中的协议行为、计费和许可仍须按验收矩阵验证。

## 评审决策

1. 首版配额按项目和子 Key 执行月度费用上限，按子 Key 执行 RPM 和并发限制。按用户、部门配置独立费用配额列入 V1.1。
2. 子 Key 绑定一个用户、一个部门和一个项目。部门与项目采用多对多授权，跨部门项目按调用归属部门隔离数据。
3. 默认保存调用元数据、风险信号和管理审计，内容审计采用内存检测和受限、脱敏的风险摘要。留存期限和试点模型由企业负责人确认。
4. 报表按账本原币显示。试点固定 USD 价目及配额，历史价格按生效时间保留。
5. 首版优先采用 LiteLLM 开源版。上线前锁定并核验版本、镜像、许可及三条首发路由。
6. OpenAI Responses 拟随 V1.1 的 Codex 试点验证。首发接口与试点交付边界见接入矩阵。
